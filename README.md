# SmartTrip - Agentic AI Travel Planner

SmartTrip is a student project that demonstrates personalized
travel planning, itinerary generation, sample accommodation
selection, and budget estimation using Python and Flask.

## Features

- Select a destination.
- Enter the starting location.
- Choose the duration of the trip.
- Enter the number of travellers.
- Set a total travel budget.
- Select travel interests.
- Generate a day-by-day itinerary.
- View estimated expenses.
- Explore tourist attractions.
- Select sample accommodation based on estimated cost.
- Attempt budget optimization using cheaper options.
- Print or save the generated plan as a PDF.
- Store recent trip summaries in a local JSON file.
